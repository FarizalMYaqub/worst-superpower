One line about the most useless superpower, entered in make.fun's "Worst
Superpower" bounty:

> I can read the minds of houseplants, but every one of them is only
> ever thinking 'water.'

## Run it

```sh
python3 main.py
```

The program writes the line to `/output/entry.txt` (set `OUTPUT_DIR` to
write somewhere else). It checks the text against the gate first (UTF-8,
1–140 characters), writes atomically, and verifies by reading the file
back before exiting.
